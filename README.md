# Taller CREATE en MVC con PHP y PDO

1. Copiar la carpeta a `C:\xampp\htdocs\taller_create_mvc`.
2. Iniciar Apache y MySQL en XAMPP.
3. En phpMyAdmin, importar `database/taller_create_mvc.sql`.
4. Abrir `http://localhost/taller_create_mvc/productos`.

Conexión (`config/conexion.php`): localhost, base `taller_create_mvc`, usuario `root`, sin contraseña.
